# OLK-6.6 ARM kernel BOOTS in gem5 (simulator bring-up fixed)
# Root cause: gem5's ARM release advertises FEAT_HCX (ARMv8.7) in
# id_aa64mmfr1_el1 but does not implement the HCRX_EL2 register. The 6.6
# kernel's init_el2 writes HCRX_EL2 before VBAR is set; the unimplemented
# msr traps to vector base 0 -> infinite loop at vector offset 0x200
# (found via gem5.debug Exec trace: 'msr hcrx_el2,x0' @ init_el2+140).
# Fix: drop FEAT_HCX from system.release.extensions (config-only).
