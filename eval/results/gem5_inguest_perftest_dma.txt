# How: register_seg translates the app's buffer VA -> guest PA (/proc/self/pagemap),
# rings a REGISTER-MR doorbell {token,va,pa,len}; the NIC keeps an MR table and DMAs
# guest physical memory via the gem5 System's backing store (getPhysMem). A WR carries
# (remote_token,remote_va) + (local_token,local_va); the NIC resolves both to guest PAs
# and moves the bytes between the apps' OWN buffers. Works for stock perftest AND the
# 13-verb in-guest test (k_dataplane, still 13/13).
